# AI Engineer Field Guide — 30 s promo

`out/ai_engineer_field_guide.mp4` — 1920×1080, 30 fps, exactly 30.0 s, AAC stereo.

Everything is generated by code: no stock footage, images, or samples.

| File | What it does |
| --- | --- |
| `content.py` | All on-screen copy, the palette, and the timing grid (128 BPM, 16 bars = 30 s) |
| `audio.py` | Synthesizes the soundtrack with numpy/scipy: sine-sweep kicks, noise claps/hats, sidechained saw bass, supersaw arp + pads, formant "robot vocal" stabs, risers, sub-drop impacts, reverb, tanh limiter |
| `render.py` | Draws every frame with Pillow, then post-processes it with numpy (bloom, chromatic aberration, glitch slices, beat zoom-punch, camera shake, scanlines, grain, vignette), rendering on 4 cores and piping frames into ffmpeg |
| `build.sh` | One-shot rebuild |

Visual cuts are locked to the music grid: one chapter per bar, with a zoom punch on every kick and flashes and glitches on each impact.

## Structure
| Time | Section |
| --- | --- |
| 0–3.75 s | Terminal boot sequence + loading bar |
| 3.75–7.5 s | Title slam: AI ENGINEER / FIELD GUIDE, synthwave sun |
| 7.5–22.5 s | 8 chapters × 1.875 s, each with its own animated figure (neural net, token stream, vector search, agent loop, eval bars, loss curve, ops dashboard, guardrail shield) |
| 22.5–26.25 s | BUILD / SHIP / EVAL / REPEAT strobe chant |
| 26.25–30 s | Logo lockup, URL, call to action |

## Rebuild
```bash
./build.sh        # ~2 min on 4 cores
python3 render.py --still 12.3 out/still.png   # preview a single frame
```

To change the copy, edit `content.py` and rerun.
